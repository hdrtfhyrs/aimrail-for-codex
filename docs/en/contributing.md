# Contributing

Describe the concrete problem, affected entry point, applicable conditions and the resulting behavior you want to change. Include the source or reproducible error that supports the change, with personal data and credentials removed.

Improve an existing capability where possible. Explain why the change is needed and which inputs, outputs or host assumptions it affects. Choose checks appropriate to the change; state clearly which parts you did not run. New host integrations and external tools should have explicit inputs and outputs, without importing a private environment into the core.

Preserve other contributors' changes. Keep private workspaces, account records, browser credentials and runtime databases out of the repository. Authored contributions use the repository MIT license; retain applicable third-party notices when reusing external code.

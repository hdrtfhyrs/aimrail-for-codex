# Pi host extensions and historical skills

The repository retains two user-authored extensions and their implementations. The shared root [extensions/pi-capabilities.js](../../../../integrations/pi/extensions/pi-capabilities.js) delegates to [runtime/capability-loader.js](../../../../integrations/pi/runtime/capability-loader.js), which creates an on-demand capability catalog from tools currently enabled by the host. It does not install tools or expand their scope. [extensions/pi-gpt6-fast.js](../../../../integrations/pi/extensions/pi-gpt6-fast.js) modifies requests under specified model/provider conditions. `/fast on|off|status` controls this session's priority request field, which is off by default.

Pi must supply extension APIs for command registration, event subscriptions, tool catalogs, and current-session access. Code retains original event names and model identifiers; select installation according to actual current Pi and provider support. Source files do not prove that an account has a model, quota, or priority service.

`skills/` retains the general instructions and references from the earlier Pi phase: [adaptive-research](skills/adaptive-research/SKILL.md), [adaptive-workflow](skills/adaptive-workflow/SKILL.md), and [problem-solving](skills/problem-solving/SKILL.md). Current general Codex/Claude rules are maintained by repository skills such as [evidence-research](../../skills/evidence-research/SKILL.md) and [outcome-collaboration](../../skills/outcome-collaboration/SKILL.md). Model hierarchy, news scope, and verification methods in these historical documents belong to that earlier phase and must not override current user conditions. They are retained as historical host adaptation source; they were not reinstalled or run for this release.

To use old extensions, put the shared root source files in your own Pi extension directory or load them through an explicit supported host entry point. Do not copy private settings, account connections, or conversation history. No startup or login trigger is configured.

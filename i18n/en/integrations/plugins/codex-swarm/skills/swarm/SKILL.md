# Codex swarm

Use the currently available native collaboration tools for the user-authorized task. Read [outcome-collaboration](../../../../../skills/outcome-collaboration/SKILL.md) as needed for role organization and delivery rather than duplicating its rules here.

When a module needs coordination, Sol owns its core personally and delegates execution to implementation_worker. Luna is a leaf executor; parallel additional Lunas at an upper layer when more execution capacity is needed. Clearly defined tasks may go directly to an executor without mandatory intermediate layers.

Deliver writing, analysis, organization, modifications, or development according to the actual domain. Research retains necessary originals; do not turn every task into an engineering process. The parent receives actual artifacts, integrates them, and continues the original goal. Report concurrency counts only when requested or when they affect the result. Launch counts, statistics, and summaries cannot replace deliverables.

Subagents inherit the original task's authorization and host boundaries. Routine authorized modifications do not require another approval. Use actual available tools and model configuration; do not call Pi or another external scheduler and present it as native subagents.

# English host instruction files

These files provide English instructions for the same implementations under root [`integrations/`](../../../integrations). They do not include another runtime. Run CLI commands from the repository root; the English mirror contains no `context/`, `hooks/`, extension implementation, or duplicated source manifest.

Read [AGENTS.md](AGENTS.md) for common behavior, [project-state.md](prompts/project-state.md) for project binding and persistent task updates, and [compact.md](prompts/compact.md) for continuation. English [project templates](../templates/project) keep the filenames and parsed shared-state structure required by the root code. Values such as the `无` no-ledger sentinel remain unchanged. The [fictional update example](../examples/task-update.json) uses accepted English input aliases while persistence continues to use the existing protocol.

The six [Codex role configurations](agents/codex) and seven [Claude role instructions](agents/claude) retain their original identifiers, model settings, reasoning settings, skill names, and delegation flags. They are host templates, not proof that your account can access those models or that the host accepts every configuration option. Install only into the supported agent-control location for your actual host, adapt unavailable model choices deliberately, and use the current host's permission policy. References such as `integrations/AGENTS.md` and `skills/plain-writing/SKILL.md` in role bodies are canonical logical paths: when installing the English version, make those host entry points load the English files rather than a second conflicting rule set. See [host integration](../../../docs/en/integration.md) and [skills and hosts](../../../docs/en/skills-and-hosts.md).

The [Codex swarm skill](plugins/codex-swarm/skills/swarm/SKILL.md) uses native collaboration only when explicitly requested and tools are actually available. It does not install a scheduler. The [Pi guide](pi/README.md) explains shared extension source and the translated historical Pi rules, whose old model layering and workflow gates do not replace current user conditions.

Local additions to upstream skills are in [`../skills/task-*`](../skills). They still require the official upstream skill and original host APIs. Their `UPSTREAM.md` files identify provenance and exclusions; missing upstream references and runtime assets are intentionally not supplied under this repository's MIT license. These English materials translate instructions and documentation, not every CLI output, error message, or runtime interface.

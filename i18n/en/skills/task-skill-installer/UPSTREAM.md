# Installer provenance

The original skill and Python helpers are OpenAI's system skill-installer. The installed original LICENSE.txt is Apache License 2.0; that licence is not replaced by this repository MIT licence. Only the local environment-policy replacement paragraph is included here.

Use the currently supplied installer in Codex, or obtain the upstream skill through the official distribution. Current plugin examples and building guidance are linked from [OpenAI Plugins](https://github.com/openai/plugins). The historical [OpenAI Skills catalog](https://github.com/openai/skills) now points users to the plugins repository; do not assume its old curated paths are the current installation route.

# Maintain the knowledge base

First read [plain-writing](../plain-writing/SKILL.md), then consult `workspace/memory/knowledge/INDEX.md` from the repository or configured workspace root. Maintain prose-writing methods only in that shared writing original; this entry point handles knowledge storage and continuation.

Find existing topics according to the complete task. If an applicable document exists, fill its gaps and correct outdated claims; create and register a new document within authorization only if none exists. Preserve still-valid content rather than duplicating a document for another discussion. If the user specifies a delivery directory or asks only for an explanation, follow that scope. The word “knowledge” does not automatically authorize library changes.

Use this project's actual material to explain how the domain works, where the current task fits, and which knowledge affects choices. For unfamiliar complex topics, first show the overall relationships and one actual example, then expand according to the questions. Follow the shared writing original for organization of diagrams and prose. Mark factual gaps and check current sources for key changing conclusions. Retain sources for long material so they can be expanded as needed.

Respect file ownership; read the current original before editing. On delivery, directly show the overall diagram and enough continuous prose for judgment, opening the full document when long. When changing an existing document, provide before/after excerpts from the same location, with unknowns visible in the prose. Paths are entry points for complete reading, not substitutes for showing content. Record necessary changes.

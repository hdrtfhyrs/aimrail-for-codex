# 知识库维护

先读 skills/plain-writing/SKILL.md，再查 workspace/memory/knowledge/INDEX.md。正文写法只在共用写作原件维护，此入口负责知识存放与接续。

按完整任务找已有主题；有适用文档就补缺并修正过时说法，没有才在授权范围新建并登记。保留仍有效内容，不为新一轮讨论重复建文档。用户指定交付目录或只要一份说明时按其范围办理，不因“知识”一词自动改库。

用本项目真实材料解释领域怎样运作、当前任务在其中哪一部分及影响选择的知识。陌生的复杂主题先让读者看清整体关系和一个实际例子，再按问题展开；具体图文组织沿共用写作原件。事实缺口标明，变化中的关键结论查当前来源。长资料留可按需展开的来源。

遵守文件归属，先读现用原件再改。交付时直接展示整体图和足以判断的连续正文，长文打开全文；修改已有文档时给同处前后对照，未知部分在正文可见。路径作为完整阅读入口，不能代替内容展示；记必要变化。

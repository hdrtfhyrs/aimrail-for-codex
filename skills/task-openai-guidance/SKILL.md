# 查证并完成 OpenAI 相关任务

围绕用户实际问题决定先查什么。定价、模型、API 参数与产品行为读当前官方文档；本地故障先看相关配置、源码、日志或最小复现。评估流程与使用效果时结合社区作者原帖、失败案例和本机结果，分清产品规定、作者观察与推测。已有适用原件可先用；不把官方文档搜索设为所有任务的第一动作。

官方检索优先用已提供的 OpenAI Docs 搜索与抓取工具，缺失或结果无关时用官方网页；引用实际读到的支持页面。非官方来源须标明出处与适用条件，不能代替官方 API 契约。用户明确指定的模型与目标保持原意；需要当前型号、费用或可用性时核当前事实，不凭缓存断言。

只读取当前操作需要的原文、参数与参考。选择、迁移、排障和实现可以组合，不设一次只能选一个路线的限制。涉及 API 时先核已有可用鉴权；仅改代码或本地检查无需先申请新密钥，实际请求才检查调用所需权限，输出不得包含凭据。

完成已授权工作；测试与查证沿现行AGENTS，不固定追加验证工序。说明实际覆盖、失败条件和仍未验证部分；检索工具可用或配置保存不等于用户任务已完成。

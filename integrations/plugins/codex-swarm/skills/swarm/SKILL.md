# Codex 集群

使用当前原生协作工具完成用户授权的任务。具体分层与交付方法按需读 ../../../../../skills/outcome-collaboration/SKILL.md，不在此重复一套规则。

需要模块协调时由Sol亲自承担核心并派implementation_worker执行；Luna是末端，需要更多执行量由上层并行多个Luna。任务明确时可直接派执行者，不强制层层经过。

按任务领域直接交付写作、分析、整理、修改或开发成果；研究保留必要原证，不把所有工作转成工程流程。父级收取实际成果、整合并继续原目标。只在用户要求或数量确实影响结果时报告并发数量，不用启动数、统计和摘要替代交付。

子代理沿用原任务授权和宿主边界，不需要为授权内的普通修改另加一次批准。保持实际可用的工具与模型配置，不调用Pi或另一个外部调度器冒充原生子代理。
